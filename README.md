# Notas Pucp Ciencias

Primer release oficial en español. Versión **1.2.0**.

Aplicación móvil para calcular notas finales de cursos de Estudios Generales Ciencias y de la Facultad de Ciencias e Ingeniería de la PUCP.

## Descargar

La app puede descargarse desde la sección de lanzamientos del repositorio.

- Plataforma principal: Android
- Compatibilidad prevista: Android 8 a Android 16

## Uso web

Para uso web [index.html](www/index.html)

Clona el repositorio:

```bash
git clone https://github.com/KernelX-debug/grade-calculator-pucp.git
```

Ingresa a la carpeta del proyecto:

```bash
cd grade-calculator-pucp
cd www
```

Abre el archivo principal en tu navegador:

```bash
start index.html
```

## Funciones incluidas

- Cálculo de nota final por curso con fórmulas fijas
- Promedios con descarte automático de la menor nota cuando corresponde
- Truncado y redondeo según las reglas de cada curso
- Cálculo de nota mínima necesaria para alcanzar un objetivo final
- Creación de calculadoras personalizadas con evaluaciones, cantidades y porcentajes de peso
- Búsqueda de cursos por código o nombre
- Persistencia local de notas y calculadoras personalizadas
- Exportación e importación de copias de seguridad
- Modo diurno y modo oscuro
